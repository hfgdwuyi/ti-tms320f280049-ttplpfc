# TTPLPFC — Totem-Pole Bridgeless PFC on TMS320F280049C

Single-phase **Totem-Pole Bridgeless PFC** digital control firmware running on the Texas Instruments **TMS320F280049C** (C2000 DSP).

## Overview

| Item | Detail |
|------|--------|
| Topology | Single-phase Totem-Pole Bridgeless Boost PFC |
| MCU | TMS320F280049C (C2000, 32-bit DSP) |
| Switching frequency | 100 kHz (ePWM1) |
| Control architecture | Dual-loop PI: outer voltage loop + inner current loop |
| Toolchain | CCS v11.1.0 / C2000Ware 4.03 / TI CGT 22.6.0.LTS |
| Power range | 1–3 kW |
| Bus voltage target | 400 V |
| Grid frequency | 60 Hz (configurable) |

## Control Architecture

```
ePWM1 ISR @ 100 kHz (every 10 µs)
 │
 ├─1. Adc_Cal_100KHz()      — ADC read + zero-offset centering
 ├─2. VoltLoopCtrl()         — Voltage loop PI (decimated /10 → 10 kHz)
 ├─3. Iref_Cal()             — Sinusoidal current reference from grid voltage
 ├─4. CurrLoopCtrl()         — Current loop PI @ 100 kHz
 └─5. PWMDriver_Ctrl()       — Duty update + polarity state machine
```

### Voltage Loop (Outer)

- **Rate**: 10 kHz (100 kHz ISR decimated by 10)
- **PI controller** with back-calculation anti-windup (`Kc = 0.3`)
- **Input**: Vbus per-unit (`VDC_ADC / 4000`)
- **Output**: Current reference multiplier, limited to `[0, Out_Max]`
- **Soft-start**: Vbus reference ramps from 0.10 pu in steps of 0.0005 per iteration

### Current Loop (Inner)

- **Rate**: 100 kHz (full ISR rate)
- **PI controller** with back-calculation anti-windup (`Kc = 0.3`)
- **Input**: Inductor current per-unit (`(IAC_ADC - 1893) / 3000`)
- **Output**: PWM duty, limited to `[Out_Min, Out_Max]`

### Current Reference Generation

The sinusoidal current reference is generated by multiplying the voltage loop output with a normalized grid voltage waveform:

```
vacAbsFilt  = LPF(|VAC_ADC - offset|)       // moving-average of rectified grid
vacNorm     = (VAC_ADC - 2048) / vacAbsFilt  // normalized to [-1, +1]
iRefPu      = Vloop.Out × vacNorm            // sinusoidal, in-phase with grid
```

## PI Controller Implementation

Both loops use `PI_RunAw()`, a PI controller with back-calculation anti-windup:

```c
err    = ref - fb;
uUnsat = (Kp × err) + Integrator;
uSat   = clamp(uUnsat, Out_Min, Out_Max);
Integrator += (Ki × err) + Kc × (uSat - uUnsat);   // Kc = 0.3
```

The anti-windup term `Kc × (uSat - uUnsat)` pulls the integrator back when the output saturates, preventing windup during startup transients and load steps.

# Kp / Ki Parameter Configuration by Power Level

The PI gains below are tuned for a **400 V bus**, **100 kHz switching**, **60 Hz grid**, with the same per-unit scaling as the firmware defaults. Choose the row matching your target power and use it as the **starting point** for bring-up.

## Recommended Parameter Table

| Power | Vloop Kp | Vloop Ki | Vloop Out Max | Iloop Kp | Iloop Ki | Iloop Out Range | Iref Max | Soft Ramp Step |
|------:|---------:|---------:|:-------------:|---------:|---------:|:---------------:|:--------:|:--------------:|
| **1 kW** | **0.045** | **0.0010** | 0.75 | **0.18** | **0.0045** | 0.04–0.90 | 0.70 | 0.0004 |
| **2 kW** | **0.060** | **0.0015** | 0.90 | **0.25** | **0.0080** | 0.05–0.95 | 0.90 | 0.0005 |
| **3 kW** | **0.072** | **0.0022** | 0.95 | **0.32** | **0.0110** | 0.06–0.97 | 0.95 | 0.0007 |

> **Note**: The firmware defaults match the **2 kW** row. All gains are in **floating-point per-unit** — they assume the ADC scaling (`/4000` for voltage, `/3000` for current) and PWM scaling in the code are unchanged.

## How Gains Scale with Power

At higher power, the inductor current is larger for the same per-unit reference, so:

- **Current loop Kp/Ki increase** roughly proportional to √P — higher current needs more loop gain to maintain the same bandwidth and disturbance rejection.
- **Voltage loop Kp/Ki increase** proportionally — the voltage loop sees larger load steps, so it needs more aggressive response.
- **Output limit ranges widen** — higher power needs more headroom on the duty cycle.

## Tuning Procedure (Bring-Up Sequence)

### Step 1 — Current Loop Only

```
Vloop disabled (b1LoopClose = 0)
Fixed small iRef (e.g., 0.15 pu)
```

1. Start with the recommended Kp/Ki for your power level.
2. Reduce Kp by 50%, increase until you see ~2–3 kHz bandwidth (no oscillation).
3. Slowly increase Ki until steady-state error vanishes.
4. Verify: inductor current tracks the sinusoidal reference with low THD.

### Step 2 — Voltage Loop

```
Enable voltage loop with low Ki
Soft-start ramp active
```

1. Keep the tuned current loop gains.
2. Start with **Ki = 0** (P-only), bring Kp to ~70% of the table value.
3. Add Ki gradually until bus voltage settles within 2–3 line cycles after a load step.
4. **Do not push Ki too high** — excessive voltage-loop Ki couples 120 Hz ripple into the current reference, increasing current THD.

### Step 3 — Full-Load Validation

1. Increase load in steps (25% → 50% → 75% → 100%).
2. At each step, check:
   - Bus voltage overshoot < 5%
   - Recovery within 5 line cycles
   - Input current THD < 5% at full load
   - No audible noise or oscillation
3. If the bus oscillates at light load, reduce Vloop Ki by 20–30%.

## Key Constants

These are defined in [`include/Constant.h`](include/Constant.h) and affect the per-unit scaling that the gains operate on:

| Constant | Value | Meaning |
|----------|-------|---------|
| `ISR_EPWM_FREQ` | 100000 | ISR / current loop rate (Hz) |
| `ADC_VAC_VOLT_ZERO_1V6` | 2048 | Grid voltage ADC offset (1.65V) |
| `ADC_VAC_CURR_ZERO_1V5` | 1893 | Current ADC offset (1.525V) |
| `PWM_DUTY_MAX` | 450 | Max CMPA value (TBPRD=500, 90%) |
| `GRID_AC_FREQ` | 60 | Nominal grid frequency (Hz) |

**Important**: If you change any of these scaling constants, the PI gains in the table above must be re-tuned — they assume the original per-unit normalization.

## System State Machine

```
INIT → SWITCH → ACDC (main operating state)
                  ├─ INIT       — wait for grid RMS OK
                  ├─ SOFTSTART  — ramp Vbus reference
                  ├─ NORMAL     — steady-state operation
                  ├─ SHUTDOWN   — fault recovery
                  └─ FAULT      — fault handling
```

## Fault Protection

| Fault | Protection |
|-------|-----------|
| Bus overvoltage | OVP comparator + firmware threshold |
| Bus undervoltage | Firmware threshold |
| Grid over/under voltage | RMS check (configurable thresholds) |
| Overcurrent | Cycle-by-cycle + firmware threshold |
| Overtemperature | 2-channel NTC sensing |
